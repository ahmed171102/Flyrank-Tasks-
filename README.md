
# Task API

Simple in-memory to-do **CRUD API** built with **Node.js + Express**.
FlyRank Internship · Backend Track · Week 2 · Assignment A1.

## Features

- Full CRUD on tasks (`id`, `title`, `done`)
- Input validation (400) and not-found handling (404)
- Interactive docs via Swagger UI at `/docs`
- In-memory storage (resets when the server restarts)

## Requirements

- Node.js 18+ (or current LTS)
- npm

## Install & run

```bash
cd flyrank-task-api
npm install
npm start
# API: http://localhost:3000
# Swagger: http://localhost:3000/docs
```
